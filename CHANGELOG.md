# История изменений

## 1.109.7.11 — 2026-11-02

Первый публичный выпуск.

### Интерфейсы

- `qedra` / `Lisp.exe`: REPL (Lisp и математический режимы), выполнение файлов `.lisp` и `.mth`, `-e "выражение"`.
- `--json` — построчный протокол для агентов: `status`, `pretty`, `latex`, `conditions`, `certificate`, `steps`, `timing`.
- `--mcp` — MCP-сервер на stdio (инструменты `simplify`, `integrate`, `solve`, `math`, `guide`, …), режим `--sandbox` по умолчанию.
- `--sandbox [--allow-dir <путь>]...` — ограничение чтения файлов в любом режиме; `--version` — версия сборки.
- `--guide` и `--query` — справка по темам и запросы к библиотеке Lisp.

### Математика

- Интегрирование: Риш (трансцендентный и алгебраический случаи), рациональные функции (Эрмит, Лазар–Риобу–Трагер), специальные функции (эрф, интегральные экспоненты, Бессель, Эйри, Лежандр, эллиптические интегралы), определённые интегралы (вычеты, параметрические `piecewise`).
- Пределы (Грунц), ряды (Тейлор, Лоран, асимптотика), символьное суммирование (Госпер, Цейльбергер, Абрамов, C-конечные последовательности).
- ОДУ: первого порядка, линейные, Эйлера, Коши, системы, ряды, Ковачич, решения через специальные функции.
- Алгебра: факторизация над ℤ и ℚ(α), НОД (модулярный, Зиппель), Грёбнер (Бухбергер, FGLM, исключение), группы Галуа, денестинг радикалов, SOS.
- Линейная алгебра (жорданова форма, `exp(A t)`), LP/ILP с сертификатами, динамическое программирование.
- Теория чисел: факторизация, сертификат Пратта, Пелль, конечные поля.
- Сертификаты: производная первообразной, подстановка решений, идеальная принадлежность, численные проверки; интервальная арифметика и сертифицированные корни, интегралы и суммы.
- Пошаговые решения (`steps`: `brief`/`full`) с правилами на русском и английском.

### Браузерная версия

- Интерфейс на TypeScript (каталог примеров, ввод формул MathLive, вывод KaTeX, графики), вычисления в Web Worker; сборка .NET WASM с AOT.

### Публикация

- Самодостаточные сборки `win-x64`, `linux-x64`, `osx-x64`, `osx-arm64` (архивы в Releases).
- Лицензия 0BSD; тексты сторонних библиотек — `THIRD-PARTY-NOTICES.md`.
