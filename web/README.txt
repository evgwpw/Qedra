Qedra — браузерная версия

Как открыть
1. Распакуйте папку целиком.
2. Windows: запустите start.cmd (двойной щелчок).
   Linux/macOS: ./start.sh (нужен Python 3).
3. Браузер откроется сам: http://localhost:8080/app/index.html — если нет, откройте адрес вручную.

Почему нельзя просто открыть index.html двойным щелчком
Страница — ES-модули с Web Worker и .wasm; по file:// браузер блокирует их загрузку.
Нужен любой статический сервер: start.cmd запускает встроенный PowerShell-сервер,
start.sh — python3 -m http.server.

Что внутри
- Левое поле — входной язык (например integrate(1/(x^3+1), x)); Enter — вычислить.
- «Формула» — редактор MathLive; «График» — plot(...), plot3d(...), plot-implicit, plot-contour,
  plot_ode(...), plot_direction_field(...). Что строит «График» (подсказка на кнопке):
  * вызов plot(...) и т. п. — как записан; простое выражение от x — на [-10, 10] с автоподбором
    диапазона (сужает, если кривая не разрешается); явный диапазон — plot(sin(x^3), x, -4, 4);
  * команда dsolve(...) — решение ОДУ: с начальными условиями — одна кривая (точная, если dsolve нашёл
    формулу; иначе численная RK45, подпись «численно (RK45)»), без условий — семейство кривых для
    значений C1, C2 (-2..2) с подписью «общее решение; задайте y(x0) = … для частного»; отрезок по
    умолчанию — точка начального условия ± 5; нет формулы и нет условий — сообщение, что задать;
  * прочие команды (integrate, diff, simplify, …) — строится их ответ, если это функция от x;
    ответ без x, множество корней или параметры — сообщение с пояснением (график не создаётся).
  График решения ОДУ можно ввести и прямо: plot_ode(y'' + y = 0, y(x), [x, -5, 5], y(0) = 1, y'(0) = 0).
- «Шаги» — дерево шагов решения, «Стоп» — прерывание (рантайм перезапускается).
- Всё работает без сети: библиотеки лежат в папке приложения.

Требования
Браузер с WebAssembly (Chrome/Edge/Firefox актуальных версий). Дополнительно ставить ничего не нужно.
Сервер не требуется постоянный: страница считает всё локально, в браузере.

Для разработчика
Сборка (из каталога web): build.cmd [-i] — AOT по умолчанию, -i — интерпретаторная;
build.sh — то же для Linux/macOS. Сборка делает: npm ci -> npm run typecheck -> npm run build (Vite) ->
каталог функций (npm run gen:functions) -> dotnet publish в web\dist.
Тесты интерфейса: npm run test (135 тестов, доли секунды).
Оракул примеров (1500 запусков Lisp.exe, ~2,5 минуты) — только отдельной командой: npm run test:examples.
Перегенерация каталога примеров (web/app/src/examples.ts, ~7 минут) — только по команде: npm run gen:examples.
При обычной сборке примеры не перепроверяются: берётся уже проверенный examples.ts из репозитория.
