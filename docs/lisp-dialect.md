# Диалект Lisp проекта: чем отличается от Scheme и Common Lisp

Для тех, кто знает Scheme/Common Lisp и пишет код в `lib\*.lisp`, тесты или `-e`-пробы. Примеры проверены в интерпретаторе
(`Lisp.exe -e "..."`, результат — после `→`). Полный перечень функций — `docs\lisp-library-guide.md` (§5), модули — `docs\lisp-modules.md`.
Главное: это **не** Scheme и не CL — малое ядро, свои имена, нет многого привычного. Не угадывайте имя функции: проверьте
`(bound? 'имя)` или пробой `Lisp.exe -e "(имя ...)"`. Неизвестное имя — ошибка `Неизвестный символ: имя` во время вычисления.

## 1. Что это
Lisp-1 (одно пространство имён), вычисление аппликативное, **хвостовые вызовы без роста стека**, замыкания, макросы `defmacro`.
Одновременно — система компьютерной алгебры: выражения — обычные S-выражения (`'(+ x 1)`), арифметика от символов сама упрощает.
**Нет:** `call/cc`, `=>` в `cond`, `macroexpand`, символа `nil` (печатается, но не читается),
литералов символов `#\a`, `eq?`/`eqv?`. Многое из этого пишется в 3 строки самим.
**Есть с шага LANG:** именованный `let`, `when`/`unless`/`while`/`for-each` (prelude), `gensym`, `delay`/`force`,
потоки `cons-stream`/`stream-*`, строки (`string-length`, `substring`, …), хеш `make-hash` с ключами по `equal?`,
`do` (как в Scheme), `while`, `for-each`, `when`, `unless` — prelude.
Регистр символов значим (`Foo` ≠ `foo`); комментарий — `;`. Файл `Lisp.exe файл.lisp` сам ничего не печатает — только ваш `display`.

## 2. Истина и «unknown»
Ложь — **только `#f`**. Истинны: `#t`, `0`, `""`, `()`, символ `unknown`.
```lisp
(if '() 1 2)        ; → 1        (пустой список истинен)
(if 0 1 2)          ; → 1
(if 'unknown 1 2)   ; → 1        ; ловушка: «неизвестно» истинно
(true? 'unknown)    ; → #f       ; (true? x) — ровно #t
(positive? 'a)      ; → unknown  ; трёхзначные: in? subset? real? positive? …
(and3 #t 'unknown)  ; → unknown  ; and3 or3 not3 (логика Клини); (not 'unknown) → #f
```
Условие от трёхзначного предиката оборачивайте в `true?`. Символа `nil` нет (`nil` → ошибка). Значение «ничего»
(результат `display`, `(if #f 1)`, `(begin)`, `(t 'get отсутствующий)`) печатается как `nil`; `(null? его)` → `#t`,
но `(equal? (begin) '())` → `#f`.

## 3. Числа
* Целые — произвольной длины; рациональные `1/3` (`(/ 1 3)` → `1/3`, `(/ 6 3)` → `2`); деление на ноль — ошибка.
* Плавающие заразны: `(* 1.5 'a)` → `(* 1.5 a)`; `(+ 1/2 0.5)` печатается `1`, а `type-of` → `float`. Печать **отбрасывает `.0`**
  (`(display 2.0)` → `2`) — тип смотрите через `type-of` (`integer rational float algebraic`).
* `(sqrt 2)` → `root(1 0 -2, 0/1, 3/1)` (точное алгебраическое число); `(sqrt -4)` → `(* 2 %i)`; `(sqrt 4)` → `2`.
* `pi` и `%i` — **символы**: в Lisp-коде с кавычкой `'pi`, `'%i` (без кавычки — ошибка). `(* '%i '%i)` → `-1`.
* Численное значение — `(eval-num e)`: `(eval-num '(* pi 2))` → `6.283185307179586`; `(eval-num 1/3)` → `0.3333333333333333`.
  **Нет:** `float`, `to-float`, `exact`, `inexact`, `exact->inexact`, `round`, `truncate`, `expt`, `numerator`, `zero?`, `even?`, `odd?`, `1+`.
  Есть: `numer`, `denom` (`(numer 2/3)` → `2`), `quotient remainder modulo mod gcd lcm min max abs floor ceiling`, `integer?`, `number?`.
* Степень — `^` (не `expt`): `(^ 2 100)` → 1267650600228229401496703205376. **Ловушка:** `^` считает сразу только для целого
  основания и целой неотрицательной степени; иначе возвращает невычисленное выражение: `(^ 2 -2)` → `(^ 2 -2)`,
  `(^ 4 1/2)` → `(^ 4 1/2)`, `(^ 1/2 2)` → `(^ 1/2 2)`. Нужен `simplify`: `(simplify '(^ 4 1/2))` → `2`, `(simplify '(^ 2 -2))` → `1/4`.
* `(abs -2/3)` → `0.6666666666666666` — **известный дефект** (должно быть `2/3`); `(abs -3)` → `3`. Для рационального: `(if (< x 0) (- x) x)`.
* `(floor 7/2)` → `3`, `(floor 3.7)` → `3`. Сравнения `< > <= >=` — **ровно два** аргумента (`(< 1 2 3)` → ошибка); `+ * -` — любое число.
* Арифметика от символов сразу упрощает: `(+ 'a 1)` → `(+ 1 a)`, `(+ 'a 'a)` → `(* 2 a)`, `(* 'x 'x)` → `(^ x 2)`.
  Построить выражение **без** упрощения — `(list '+ 'a 1)` → `(+ a 1)` (потом один `simplify`).

## 4. Равенство
* `=` — только числа: `(= 1 1.0)` → `#t`, `(= 1/2 0.5)` → `#t`; `(= 'a 'a)` → ошибка `Не число`.
* `equal?` — структурное (списки, выражения, строки, символы); **числа разных типов не равны**: `(equal? 1 1.0)` → `#f`.
* `eq?`, `eqv?` **нет** — всё через `equal?`.
* Выражения сравнивайте после `simplify`: `(equal? '(+ a 1) '(+ 1 a))` → `#f`, а
  `(equal? (simplify '(+ a 1)) (simplify '(+ 1 a)))` → `#t`.

## 5. Связывание и функции
```lisp
(define x 5)                        ; → x   (define возвращает имя)
(define (f a b) (define c (+ a b)) (* c 2))   ; внутренние define работают (в теле функции и let)
(let ((a 1) (b 2)) ...)  (let* ...)  (letrec ((ev? (lambda (n) ...)) (od? ...)) ...)
(set! x 6)                          ; на неопределённое имя — ошибка
(define (g a &rest xs) (list a xs)) ; (g 1 2 3) → (1 (2 3)); (g 1) → (1 ())
```
* **Именованный `let` (LANG):** `(let loop ((i 0) (acc 0)) (if (< i 10) (loop (+ i 1) (+ acc i)) acc))` → `45`;
  тело цикла — хвостовые вызовы без роста стека (раскрытие в `letrec` + вызов).
* **`do` нет**; `while`/`for-each` — в prelude (LANG.2): `(while (< i 5) …)` — именованный let; `(for-each f l)` — эффект,
  `f` применяется ко всем элементам, результат — `()`.
* Точечные параметры `(a . xs)` — ошибка; необязательных аргументов нет (`&optional` — обычное имя параметра); `(lambda args …)` — ошибка:
  всегда список параметров, остаток — `&rest`. Число аргументов проверяется строго (`Функция ожидает 1 аргументов, получено 2`).
* Хвостовой вызов: `(define (cnt n acc) (if (= n 0) acc (cnt (- n 1) (+ acc 1))))`, `(cnt 1000000 0)` → `1000000`. Нехвостовая рекурсия:
  предел логической глубины 100000 (`(deep 10000)` ок, `(deep 1000000)` → `Превышена глубина рекурсии 100000`); поднять — `(set-max-depth n)`,
  но реальный стек кончается около 290 000 кадров (`Переполнение стека`). Накапливайте в аккумуляторе.
* Замыкания обычные: `(define (mk) (let ((n 0)) (lambda () (set! n (+ n 1)) n)))`.
* На верхнем уровне (REPL, файл без `module`, `eval`) переопределить **builtin через define нельзя** (LANG.1): `(define (car x) x)` →
  ошибка `define: имя car занято встроенной функцией`. Явный путь переопределения — `set!` (поздняя привязка сохраняется).
  Внутри `(module …)` переопределение builtin и конфликт имён модулей — ошибка загрузки.

## 6. Управление
```lisp
(cond ((< x 0) 'neg) ((= x 0) 'zero) (else 'pos))   ; без else и без совпадения → nil
(case 3 ((1 2) 'low) ((3 4) 'mid) (else 'hi))       ; → mid
(and) → #t   (or) → #f   (and 1 2) → 2   (or #f 3) → 3   (if #f 1) → nil   (begin 1 2) → 2
```
* `cond` с `=>` — ошибка (`Неизвестный символ: =>`); `(cond (5))` без тела — ошибка формата. Тест и тело пишите явно.
* `when`/`unless` (LANG.2, prelude): `(when c e1 e2)` — как `(if c (begin e1 e2) '())`; `unless` — наоборот.
* `delay`/`force` и потоки (LANG.2, prelude): `(force (delay e))` — мемоизирующее обещание (тело — один раз);
  `(cons-stream a b)` — голова строгая, хвост ленивый; `stream-car/stream-cdr/stream-null?/stream-take/stream-map/stream-filter`.

## 7. Макросы
`(defmacro (имя арг ... &rest r) тело)` — **имя внутри списка параметров**; форма `(defmacro имя (арг) …)` — ошибка `неверный синтаксис`.
Квазицитата: `` `(1 ,(+ 1 1) ,@(list 3 4)) `` → `(1 2 3 4)`. Раскрытие — при компиляции, в области имён вызывающего.
* **Макросы негигиеничны.** `` (defmacro (swap! a b) `(let ((tmp ,a)) (set! ,a ,b) (set! ,b tmp))) `` при `(swap! tmp other)`
  ничего не меняет (захват `tmp`). `(gensym)` **есть** (LANG.2, prelude): свежий символ `g1`, `g2`… — используйте его для
  временных имён в раскрытии; `macroexpand` нет.
* Экспортируемый макрос должен экспортировать и имена, на которые раскрывается (`deftest` → `register-test`).

## 8. Ошибки
```lisp
(error "boom" 1 2)                  ; сообщение «boom 1 2» (аргументы дописываются через пробел; форматирования ~a нет)
(raise (list 'no-solution "why"))   ; ошибка с произвольными данными
(try (raise (list 1 2)) (lambda (e) (error-data e)))   ; → (1 2); у error — error-data → nil
(try (car 5) (lambda (e) (error-message e)))           ; → "car: ожидается список, получено 5"
(unwind-protect (+ 1 2) (display "cleanup "))          ; очистка при любом выходе; значение — первого выражения
```
`(try выражение обработчик)` — обработчик обязателен и **должен быть функцией** `(lambda (e) …)` (`(try e 7)` при ошибке → ошибка применения).
Разбор: `error? error-message error-data error-stack`; `(error-message 5)` — ошибка (не объект ошибки). Ловится всё, что бросает ядро
(`car` от `()`, выход за границы, деление на ноль). Продолжений (`call/cc`) нет; нелокальный выход — только `raise` + `try`.
Показать проглоченные ошибки — `(set-debug! #t)`.

## 9. Данные
**Списки и пары.** `cons car cdr cadr caddr cddr list append length reverse apply`; `(cons 1 2)` → `(1 . 2)`; `(car '())` — ошибка. Есть **все** `c[ad]r` до 4 уровней, как в Scheme/Common Lisp (`caar cdar cdddr cadddr cddddr …`, prelude, с 2026-11-11).
Порядок аргументов:

| Вызов | Результат |
|---|---|
| `(nth '(a b c) 1)` | `b` — **список первым** (`(nth 1 '(a b c))` — ошибка); вне границ — ошибка |
| `(map f l)` | один список; `(map + l1 l2)` — ошибка, для двух — `(map2 f l1 l2)` |
| `(filter p l)`, `(every? p l)`, `(any? p l)` | `(filter (lambda (x) (> x 1)) '(1 2 3))` → `(2 3)` |
| `(foldl f init l)` | `f` получает **`(acc x)`**: `(foldl (lambda (acc x) (cons x acc)) '() '(1 2 3))` → `(3 2 1)` |
| `(assoc k alist)` | запись или `#f` (не `()`); значение пары `(a . 1)` — `(cdr (assoc 'a al))` |
| `(sort l less?)` | `(sort '(3 1 2) <)` → `(1 2 3)`; предикат обязателен |
| `(range n)`, `(take l n)`, `(drop l n)`, `(last l)`, `(butlast l)`, `(member? x l)`, `(append-map f l)` | prelude; `(range 3)` → `(0 1 2)`, `(range 0 5)` — ошибка |

**Нет** (проверено): `fold foldr reduce member memq assq first second rest list-ref list-tail iota remove delete flatten zip
cons* sum count-if delete-duplicates set-car! void boolean? procedure? string?`. `union` работает над множествами модуля `set`, не над списками.

**Векторы:** `(vector 1 2)`, `(make-vector n init)` (без `init` — `nil`), `(vref v i)`, `(vset! v i x)`, `(vlength v)`, `vector->list`, `list->vector`;
печать `#(1 2)`; `length` тоже работает. Границы проверяются (`vref: индекс 5 вне границ [0, 3)`).

**Таблицы:** `(define t (make-table))`; `(t 'put 'a 1)`; `(t 'get 'a)` → `1`; отсутствует → `nil` (`(null? …)` → `#t`); `(t 'values)` → `(1)`.
Других сообщений нет (`'keys 'has? 'remove 'size` — ошибка). **Ключи — только символы**: `(t 'put "s" 1)`, `(t 'put 5 1)`, `(t 'put '(1 2) 1)` — ошибка.
**Хеш-таблицы (LANG.1)**: `(make-hash)` + `hash-ref`/`hash-set!`/`hash-has?`/`hash-remove!`/`hash-keys`/`hash-count` — ключи любые значения по `equal?`
(числа, строки, списки-выражения; `1/2` и `2/4` — один ключ, `1` и `1.0` — разные); `(hash-ref h k умолчание)` — умолчание при отсутствии.

**Строки** (литерал `"…"`, `\n`, `\t` работают): `string-append` (не-строка — **ошибка**, LANG.1; раньше молча давал мусор),
`to-string` (число, выражение, `1/3`), `string->symbol`, `string-contains?`, `equal?`, и `length` строки (`(length "abc")` → `3`).
**LANG.1 добавил:** `string-length`, `substring` (индексы вне — ошибка), `string-ref` (→ одно-символьная строка), `string->list`/`list->string`,
`string->number` (дробь точно; не число — `#f`), `number->string`, `symbol->string`, `string?`, `string=?`, `string<?`, `string-split`/`string-join`,
`string-upcase`/`string-downcase`, `string-index` (позиция или `#f`), `format` (`~a` display, `~s` write, `~%` — перевод строки, `~~` — тильда).
Символов-литералов `#\a` нет (типа char нет: `string-ref` даёт строку из одного символа).

## 10. Вывод
`(display x)` — строка без кавычек, прочее — Lisp-запись (`(display '(1 "a" b))` → `(1 "a" b)`); `(newline)`. `print`/`write` нет; `format` — есть (LANG.1: `~a`, `~s`, `~%`, `~~`).
`display` возвращает «ничего» (`nil`). `Lisp.exe -e "(+ 1 2)"` печатает значение **последней** формы (ограничение 2000 знаков).
`--math -e "2x+1"` — входной математический язык (`docs\math-language.md`); из Lisp — `(math-eval "2x+1")` → `(+ 1 (* 2 x))`.

## 11. Ключевые слова, модули, загрузка
* `:имя` самовычисляется (`:foo` → `:foo`, `(equal? :a ':a)` → `#t`), это символ (`(symbol? :a)` → `#t`); для опций (`:where`, `:comment`). `(define :x …)` — ошибка.
* `(module имя (export a b))` — первая форма файла; остальное в файле приватно, снаружи — `модуль::имя`:
```lisp
; m1.lisp: (module m1 (export pub))  (define (priv x) (* x 2))  (define (pub x) (priv x))
(load "m1.lisp")  (pub 2) → 4   (priv 2) → ошибка   (m1::priv 2) → 4
```
* `(load путь)` выполняет файл в текущем окружении (путь — от рабочего каталога; библиотека — `lib-dir`). Prelude (`lib\prelude.lisp`) загружается
  сам; `(bound? 'имя)` — есть ли имя, `(describe x)` — тип и происхождение. `(eval выражение)` — в глобальной области (локальные не видны).

## 12. Выражения CAS как данные
* Выражение — список с символом-головой, цитируется: `'(+ x 1)`, `'(* 2 (^ x 2))`; `(type-of '(+ a 1))` → `expr`. Голова — `+ * ^` и т. д.
  (`(- a b)` в канонической форме — `(+ a (* -1 b))`). `(simplify '(+ x x 1))` → `(+ 1 (* 2 x))`; `(expand '(* (+ x 1) (+ x -1)))` → `(+ -1 (^ x 2))`.
* **Порядок аргументов:** `(diff x e)` — **переменная первой** (`(diff 'x '(^ x 2))` → `(* 2 x)`; `(diff '(^ x 2) 'x)` — ошибка);
  `(integrate e x)` (обратный порядок тоже принимается, но пишите `e x`); `(subst правило e)` — **правило первым**.
* Подстановка: правило `(= x 5)`, `(x 5)` или список правил: `(subst '(= x 5) '(+ x y))` → `(+ 5 y)`; `(subst '(x 5) '(+ x 1))` → `6`;
  `(subst '((x 1) (y 2)) '(+ x y))` → `3`. Подставлять можно только символы; `(subst '(+ x 1) 'x 5)` — ошибка (два аргумента).
* `(replace-expr e u v)` — замена подвыражения (`(replace-expr '(+ a 1) 'a 'b)` → `(+ b 1)`); `(op-expr? e)`, `(contains-sym? e x)`.
* Построить выражение: `(list '+ a b)` (не упрощает) либо `(+ a b)` (упрощает сразу). Домены и декларации — `docs\lisp-library-guide.md` §2.

## 13. Тесты
`tests\Lisp.Tests\lisp\имя.lisp` — формы `(deftest "имя" тело...)`; внутри `assert-equal` (`equal?`), `assert-true`, `assert-error`:
```lisp
(deftest "сложение" (assert-equal (+ 1 2) 3))
(deftest "ошибка"   (assert-error (car 5)))
(run-tests)   ; только в файле-пробе: «ok   имя» / «FAIL имя: получено 2 [2], ожидалось 3 [3]»
```
Тесты одного файла делят окружение — библиотечные функции не переопределять. Подробно — `docs\lisp-library-guide.md` §7.

## 14. Проверка файла: --check
`Lisp.exe --check файл.lisp [файл2 ...]` — статическая проверка **без выполнения** кода (prelude загружается только ради списка имён).
Формат: `файл:строка:столбец: ошибка|предупреждение: сообщение`; код выхода 1, если есть ошибки; `--check --json` — массив
`{file,line,col,severity,code,message}`. Прогоняйте перед тестами на каждом изменённом `.lisp`.
* **Скобки (ошибки):** незакрытая `(` — позиция самой внутренней и «вероятное место `)`» по отступам (строка, начинающаяся не глубже
  строки открытия формы; чтение продолжается с `(` в первом столбце), лишняя `)`, незакрытая строка, `#\a`/неизвестное `#…`, неверная точка.
* **Формы (ошибки):** `let` без списка привязок/неверная привязка, `if` с > 3 аргументов, `lambda` без списка параметров, `cond`/`case`
  с веткой не списком или без тела, `define` на верхнем уровне поверх builtin, арность вызова функции из того же файла и функций
  библиотеки (по списку параметров); для builtin — только ручная таблица (`car cdr cons map filter foldl nth …`).
* **Имена (предупреждения):** неизвестное имя в позиции оператора или значения (с подсказкой: `print` → display/newline, `expt` → `^`,
  опечатки — ближайшее имя). Цитаты (`'x`, `` `x `` кроме `,x`), локальные имена (lambda/let/let*/letrec/именованный let/do/внутренние
  define), `:ключевые слова`, экспорты всех модулей `lib\` и `модуль::имя` — известны. Тело `assert-error` не проверяется (ошибка ожидается).
* Ограничения: аргументы макросов, определённых в самом файле или неизвестных проверщику, не просматриваются; `.mth` пропускаются;
  имена, создаваемые `eval`/`load` с вычисляемым путём, неизвестны. Реализация — `src\Lisp.Core\Checker.fs`.

## 14a. Запросы к коду: --query
`Lisp.exe --query <вид> <арг> [--json] [--no-body] [--depth N] [--file F]` — точные факты о коде `lib\` вместо чтения файлов целиком
(индекс строится в памяти за ≈ 1–2 с; код не выполняется; MCP-инструмент `code` — те же виды). Имена: `имя` или `модуль::имя`.
* `def NAME` — файл:строка, сигнатура, модуль/экспорт, комментарий над определением и исходный текст (`--no-body` — без текста);
  `sig NAME` — одна строка `(имя парам…) — модуль[, exported] — первая строка комментария — файл:строка` (builtin — по `lisp-library-guide.md`).
* `outline FILE` — определения файла с номерами строк (`*` — экспорт); `module NAME` — экспорты и модули, от которых зависит; `deps FILE` — внешние имена по модулям.
* `refs NAME` — ссылки (файл:строка, в каком определении; включая `tests\`, `examples\`, `bench\`); `callers`/`callees NAME [--depth 2]`.
* `search ТЕКСТ` — десять лучших определений (и builtin из `lisp-library-guide.md`): BM25 по стемам (рус./англ.; поля: имя > комментарий > строка справочника > модуль; экспорт — небольшой бонус); запрос расширяется глоссарием `docs/search-glossary.txt` (строка = группа синонимов через `|`, фраза из слов срабатывает целиком; вес ниже прямого совпадения); слово без попаданий (опечатка) ищется по триграммам. Альтернативы через `|`: `search "бесквадратное разложение | sqfree"` — объединение (максимум оценки); точное имя — всегда первым. `unused` — приватные без ссылок и экспорт без ссылок.
* Неизвестное имя → «нет такого имени; возможно: …», код выхода 1. Ограничения: ссылки — по именам (локальные имена учтены, `apply 'f` — как `'имя`);
  определения, порождённые макросами или `eval`, не видны; комментарий — строки `;` непосредственно над формой (или первые внутри).

## 15. Частые ошибки
1. `let loop`, `while`, `when`, `unless`, `do`, `string-length`, `substring` — есть (LANG); `fold`, `expt`, `float` — нет; замены выше.
2. `(if (positive? x) …)` — `unknown` истинно: пишите `(if (true? (positive? x)) …)`.
3. `(= a b)` для выражений — ошибка: `equal?` после `simplify`. `(equal? 1 1.0)` → `#f`.
4. `(^ 2 -1)` — точная дробь 1/2 (LANG.1); `(^ 4 1/2)` не вычисляется — нужен `simplify`; `pi`/`%i` — только с кавычкой.
5. Порядок: `(nth l i)`, `(diff x e)`, `(subst rule e)`, `(foldl f init l)` с `f (acc x)`; `map` — один список (`map2` для двух).
6. `(string-append "a" 5)` — теперь ошибка (LANG.1): `to-string`. Ключ `make-table` — только символ; произвольный — `make-hash`.
7. `(try e handler)` — обработчик-функция `(lambda (e) …)`; `assoc` без совпадения → `#f`, `(t 'get …)` → `nil`.
8. Макросы негигиеничны; `(gensym)` (LANG.2) — свежие имена внутри раскрытия.
9. `(define (car …))` на верхнем уровне — ошибка «занято встроенной функцией» (LANG.1); не называйте свои функции как builtin (переопределение — только через `set!`).
10. Нехвостовая рекурсия глубже ≈ 100000 — ошибка: аккумулятор.
11. Результат `display` — `nil`, а не значение: не ставьте `display` последним в теле, если результат нужен.
12. `(abs x)` от рационального даёт float (известный дефект).
